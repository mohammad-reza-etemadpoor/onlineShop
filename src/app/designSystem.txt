For **Little Loom**, I'd position the brand as **modern, premium, warm, and trustworthy**—something that appeals to parents without feeling overly childish. The design should be clean and soft, letting the products stand out.

# Motion

Keep animations subtle:

* 150–250ms duration
* Fade-ins for content
* Scale to 1.03 on card hover
* Smooth button hover transitions
* Slide-in mobile menu

Avoid bouncy or distracting animations.

# Accessibility

* Meet WCAG AA color contrast where applicable.
* Minimum touch target size of **44×44px**.
* Visible keyboard focus indicators.
* Semantic HTML and proper ARIA labels.
* Alt text for all product images.

## Tailwind CSS Design Tokens

```js
colors: {
  primary: "#F9E34F",
  cream: "#FFF9EB",
  peach: "#FFD9C8",
  success: "#5DBB63",
  warning: "#F4A261",
  danger: "#E76F51",
},

borderRadius: {
  sm: "8px",
  md: "12px",
  lg: "16px",
  xl: "20px",
  full: "9999px",
},

fontFamily: {
  heading: ["Poppins", "sans-serif"],
  body: ["Inter", "sans-serif"],
},
```

This design system will give **Little Loom** a cohesive, premium identity while remaining approachable and family-friendly. It also maps cleanly to a React + Tailwind CSS component architecture, making it easy to maintain and scale as your catalog grows.
